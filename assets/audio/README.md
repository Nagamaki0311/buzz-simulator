# audio アセットについて

このディレクトリには、以下の効果音・環境音の音源ファイル（mp3等）を配置する想定です。

- 紙をめくる音（スピン開始時）
- 墨を書く音（役成立時）
- 成立SE
- ボタン押下音
- 環境音（BGM）

現時点では実際の音源ファイルが用意されていないため、`src/engine/AudioEngine.js` は
Web Audio APIによる暫定的な合成音（サイン波）で代替しています。
実際の音源ファイルをこのディレクトリに配置した後、AudioEngine.js の `play()` 内の
実装を `AudioBufferSourceNode` による再生に差し替えてください
（呼び出し側のインターフェース `play(soundId)` は変更不要です）。
